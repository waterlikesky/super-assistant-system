**可复用点**

- 「本地解密 → 结构化 → Agent 只读」路径，而非机器人协议。

**别人怎么做**

**与自建系统关系**

- 微信 connector 应标为 **可选插件 + 高脆弱**，默认关闭。

## 提炼：对「自己建系统 + GPT 协作」的建议

1. **分层**：只读接入 → 统一 schema → 本地记忆 → Agent；出站默认关。
2. **越用越聪明** = 摘要 / 事实抽取闭环，不是堆 raw 聊天。
3. **微信最后做、可选、版本钉死文档**；邮件 / 导出先做。
4. **与 GPT 协作**：把坑文档和 M0–M3 计划当合同；每 PR 只交付一个可验收切片。
5. **诚实**：社区帖里的工具会挂、会下架；仓库里写「已知脆弱」比写「已打通微信」更有价值。
