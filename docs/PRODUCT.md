# 产品定义（一页）

## 是什么

**超级助理（sas）是跑在你自己电脑上的「个人语境 OS」。** 它只读地吃进你从微信、钉钉、邮件、短信导出的聊天记录，脱敏后存进本地一个 SQLite 文件，从中持续抽出「人、事实、承诺、待办、偏好」，让你用一句话问回来。

不是聊天机器人，不是 SaaS，不替你发消息。

## 为你每天做什么

| 你想知道 | 命令 | 它怎么答 |
|---------|------|---------|
| 我上次和老王聊了什么？ | `sas ask "上次和老王聊了什么"` / `sas person 老王` | 最近一次会话的时间、渠道、关键几句，每句带出处 id |
| 我答应过谁什么？ | `sas todos` / `sas ask "我答应过谁什么"` | 从**你发出**的消息里抽「我明天把报价发你」类承诺，列出对象、原话、期限；后续你说「发你了」会自动关闭 |
| 别人找我办的事 | `sas todos` | 从对方消息里抽「帮我/麻烦你/记得…」类请求 |
| 今天该回谁？ | `sas todos`（待回复）/ `sas ask "今天该回谁"` | 会话最后一条是对方发来的提问或请求、且你还没回 |
| 今天发生了什么 | `sas digest --date 2026-10-06 --out ~/Obsidian/日报/` | 每日摘要：各渠道量、每个会话要点、新承诺/待办、新学到的事实；Markdown 带 `[[人名]]` 链接 |
| 这个人是谁、喜欢什么 | `sas person 老王` | 人物画像：渠道、往来次数、首次/最近联系、事实与偏好（带置信度）、未完成事项 |
| 搜任何一句话 | `sas ask "报价单"` | 中文全文检索（FTS5 trigram） |

「越用越聪明」的具体含义：每次 `sas ingest` 新导出，只处理新增消息 → 抽取 → 与已有记忆合并（同一事实被多次提到，置信度上升；长期没再提起，按半衰期衰减；承诺被后续消息关闭）→ 下次提问命中的是更新后的记忆。

## 不做什么

- **不发消息**：代码里没有任何发送通道；出站配置即使打开也会被拒绝。
- **不解密微信、不 Hook、不用协议号**：只吃 WeChatMsg（留痕）等工具的**导出文件**。
- **不上传**：默认全离线规则；接本地 Ollama 可选；云模型需显式开关，且只发脱敏后的片段，不发全文。
- **不做企业系统集成**：钉钉只吃你自己导出的 csv/xlsx。
- 不追求「一次吃掉人生全部数据」：你指哪个导出，就摄入哪个。

## 隐私边界

| 规则 | 实现 |
|------|------|
| 本地优先 | 所有数据只在 `./data/sas.db`（gitignore）；删除该文件即全部遗忘 |
| 入库前脱敏 | 手机号、验证码、身份证、银行卡、邮箱、快递单号在写库前替换；含验证码的消息整条替换 |
| 原文不复制 | `raw_ref` 只记本机路径 |
| 云模型默认关 | `SAS_ALLOW_CLOUD_LLM=false`；打开后也只发脱敏片段，`confidential` 消息永不外发 |
| 出站永久关 | 无发送实现；`SAS_OUTBOUND_ENABLED=true` 会直接报错 |
| 同意可追溯 | 每条事件带 `consent_tag`（默认 `cli:<日期>`） |
